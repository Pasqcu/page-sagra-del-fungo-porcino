# Page Sagra del Fungo Porcino

Landing page QR ordini sagra del fungo porcino rocca priora

**Live:** https://pasqcu.github.io/page-sagra-del-fungo-porcino/

## Stato attuale

`index.html`: landing page informativa (hero, programma, menù, info pratiche).
Un solo file, CSS inline, nessuna build, nessuna dipendenza.
Font da Google Fonts (Fraunces + Inter).

Il flusso **ordini da QR** non è ancora implementato: la pagina oggi mostra il menù,
non permette di ordinare.

## Dati da sostituire

Contenuti segnaposto, non dati reali:

- date (`21 – 23 Settembre 2026`)
- indirizzo esatto e piazza a Rocca Priora
- orari del programma
- prezzi del menù

## Modifiche

Modifica `index.html`, committa su `main`. Il push aggiorna GitHub Pages in circa un minuto.
